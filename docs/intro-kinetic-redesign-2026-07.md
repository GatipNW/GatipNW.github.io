# ข้อเสนอ: ยกเครื่อง Intro ให้ปังแนว Persona (Kinetic) — "คลื่นหมึกราตรี"

> สถานะ: **เอกสารเสนอ (proposal) — ยังไม่ implement** · วันที่ 2026-07-25
> ให้เจ้าของรีวิวก่อน แล้วค่อยตัดสินใจว่าจะเริ่มทำหรือปรับตรงไหน

## 1. เป้าหมาย

ทำฉากเปิดเว็บ (intro/Title) ให้ "ปัง" ขึ้นแนว opening ของเกม Persona
โดยเอามาแค่ **พลังงานการเคลื่อนไหว** — ตัวอักษรเคลื่อนไหวมีสไตล์ (kinetic
typography) + ทรานสิชันกราฟิกเฉียบๆ ทุกช่วง — เรนเดอร์ด้วยธีมเดิมทั้งหมด
บน Canvas 2D **ไม่แตะ WebGL / ไม่เพิ่ม framework / ไม่เพิ่ม CDN**

## 2. ข้อสรุปจากการคุย (ล็อกแล้ว)

| หัวข้อ | ตัดสินใจ |
|---|---|
| ธีม/ลุค | **คงคราม×ชาด×วาชิ ฟอนต์ Shippori Mincho** — ยืมแค่ "โมชัน" ของ Persona ไม่ทำแดง-ดำ street/pop (จะชนธีมทั้งเว็บ + OG/แบรนด์) |
| ขอบเขต | **ทั้ง flow** — ใส่ทรานสิชันเฉียบทุกรอยต่อ (title→charge→leap→lang→dialog→enter→zoom) |
| ความเข้ม | **refined-bold** — โมชันหนักได้ แต่ **ชื่อ NIPITH ต้องอ่านออกคมชัดเสมอ** (HR ต้องอ่านได้) · แต่ละ seam ได้ "ท่าไม้ตายเดียว" ไม่กองรวม |
| ฉากหลัง | เพิ่มมิติแบบ cinematic แต่ **ไม่เพิ่มของรก** (ดูข้อ 4) |
| วิธีทำ | ทำ **1 รอยต่อเป็น prototype ก่อน** ให้เจ้าของเปิดดูจริง (โมชันต้องรู้สึกเอา) แล้วค่อยโรลเอาต์ |

## 3. Motion Language "คลื่นหมึกราตรี" — ชุดคิเนติก (kit) 5 ชิ้น

สร้างเป็นชิ้นส่วนใช้ซ้ำได้ วาดเป็น sprite แคชไว้ (drawImage ล้วน — ไม่กิน perf):

| # | ชิ้น | หน้าตา (แปลงเป็นธีมเรา) | ใช้ตรงไหน |
|---|---|---|---|
| 1 | **คลื่นหมึกกวาด** | คลื่นเซกาอิฮะคราม/ชาดกวาดข้ามจอ ปิด→เผย | แทน fade จืดระหว่าง state |
| 2 | **ม่านชาด (shutter)** | แถบชาดทแยงสแนปเข้า-ออกแบบ Persona shutter | ตัดแรง: leap ตูม / ตัดเข้าห้อง |
| 3 | **ตราคันจิ** | ตัว 月 / 翻訳 ตัวใหญ่กระแทกลงจอ + หมึกสาด แล้วจาง | จังหวะพีค (leap, เข้าห้อง) |
| 4 | **ตัวหนังสือคิเนติก** | role line / tagline / คำถามภาษา สแนปเข้าบนแถบชาดเลื่อน + ขีดทองกวาดใต้ | ทุกที่ที่มีข้อความโผล่ |
| 5 | **เส้นความเร็ว** | เส้นทองพุ่งเข้าศูนย์กลาง | charge→leap |

## 4. ฉากหลัง (background) — เพิ่มมิติ ไม่เพิ่มความรก

ฉากหลังปัจจุบัน (5 เลเยอร์ bg-sky/moon1+moon2/bg-mid/bg-near + พารัลแลกซ์เมาส์
+ 2 ดวงจันทร์ + เมฆ + หมอกเชิงเขา 3 ชั้น + ผิวน้ำระยิบ + แฟรี่ 6 ตัว + ดาวตก
+ บอเก้) **สวยและแน่นอยู่แล้ว — คงไว้ทั้งหมด** แล้วเสริม 3 อย่างที่คุมได้:

1. **กล้อง 2.5D ดัน/ดริฟท์ตอนทรานสิชัน** — เวลาสลับ state ให้กล้อง push-in
   หรือดริฟท์เบาๆ (เลเยอร์ขยับต่างความลึก) = ฉากรู้สึก cinematic ไม่นิ่งแข็ง
2. **หมึกกวาดเคลือบท้องฟ้าชั่วขณะ** — ตอนจังหวะพีค (leap / เข้าห้อง) มี ink-wash
   คราม/ชาดกวาดเคลือบฟ้า ~0.4s แล้วเคลียร์กลับฉากเดิม = พลังกราฟิกแบบ Persona
   แต่ไม่ค้างเป็นของรก
3. **ลายเซกาอิฮะ/อาซาโนฮะ ghosted จางมากในท้องฟ้า** (เท็กซ์เจอร์)
   — ★ **ตั้งปิดเป็นค่าเริ่มต้น** เปิดได้ผ่าน flag กันรก (เจ้าของไวกับความรกมาก)

★ **ไม่เอากลับ** (เจ้าของถอดถาวรเพราะ "รก"): moonbeam · god rays หลังโลโก้
· ประกายดาว 4 แฉกบนตัวอักษรโลโก้

## 5. แม็พลง flow — แต่ละรอยต่อได้ "ท่าไม้ตายเดียว"

| ช่วง | ของเดิม | เพิ่ม/ยกระดับ |
|---|---|---|
| **Title เปิด** | letter-slam + logo gradient | คง letter-slam · +ขีดทองกวาดใต้ชื่อ · role line สแนปบนแถบชาด · ตรา 月 มุมจอ |
| **PRESS START → charge** | letterbox + สั่นรัว | +เส้นความเร็วพุ่งเข้า · ม่านเริ่มหุบ |
| **leap (ตูม!)** | โลโก้แตกเป็น particle | +ตรา 翻訳 กระแทก + หมึกสาด (ขยายของเดิม) |
| **→ เลือกภาษา** | เก็บ letterbox + กล่องวาชิ | +คลื่นหมึกกวาดเผยการ์ด · การ์ดสแลมเข้าทีละใบ |
| **lang → dialog** | fade | +ม่านชาดเร็ว · กล่อง dialog สไลด์เข้าขอบคิเนติก |
| **dialog → enter/zoom** | zoom เข้าดวงจันทร์ + แฟลช | +ม่านชาด + ตราคันจิ บนแฟลชก่อนเข้าห้อง |

## 6. กฎที่ต้องรักษา (guardrails — ห้ามพลาด)

- **reduced-motion**: kit ลดเหลือ fade สะอาดเร็ว (เครื่องเจ้าของปิด Windows
  animation + เป็น a11y requirement) — แต่โมชันหลักเป็น JS/Canvas เล่นได้อยู่แล้ว
  ต่างจาก CSS transition
- **60fps**: ทุกทรานสิชัน = drawImage ของ sprite พรีเรนเดอร์ · **ห้าม**
  createGradient / shadowBlur ต่อเฟรม · เคารพ particle cap (title 420)
- **ข้ามได้ทุกช่วง** — ปุ่ม skip เดิมต้องยังทำงาน
- **ไม่แตะ**: LOGO_STOPS (ไล่สีโลโก้) · ชื่อ 2 บรรทัด · tagline PORTFOLIO · OG/meta
- **i18n**: ถ้ามีข้อความใหม่ ต้องครบ th/en/ja (ตรา 翻訳/月 เป็นกราฟิก ไม่ใช่ข้อความแปล)
- **มือถือ/จอสัมผัส**: ทรานสิชันต้องไม่ทำให้จอ ≤360px แตก · เทส `mobile.py`

## 9. ความเสี่ยง / จุดต้องระวัง

- **"รก"** — เจ้าของไวกับความรกมาก (ประวัติถอด moonbeam/god rays/ของตกแต่ง)
  → ยึด "ท่าไม้ตายเดียวต่อ seam" ตัดได้ตัด
- **readability ชื่อ** — โมชันห้ามกลบชื่อ NIPITH (คือหัวใจที่ HR ต้องอ่าน)
- **perf มือถือ** — sprite เยอะขึ้น ต้องวัดจริง
- **งานใหญ่** — แตะ intro ที่ผ่านรอบ FINAL มาแล้ว → ทำเป็นสเต็ป ย้อนกลับได้
  ทุกขั้น ไม่รื้อทีเดียว

## 10. ทางเลือกที่ **ไม่** เลือก (บันทึกไว้)
