A playable resume by **Nipith Wongsirikul (Gatip)** — game localization (JA/EN → TH),
LQA and Thai-market marketing. Walk around a small library on the moon: an arcade wing
of four cabinets for game work, six book sets for everything else, and a reception desk
with contact details, documents and the business card. Or skip the game and read the
plain resume from the front page.

## Features

- **Thai / English / Japanese.** Every string lives in [`js/data/content.js`](js/data/content.js);
  `?lang=` in the URL wins, then the saved choice, then English. Switching re-renders
  open panels with no reload.
- **One games dataset** (`GAMES` in `content.js`) feeds both the cabinet carousel/grid
  and Resume Mode — titles, roles and release status are never typed twice. Adult
  titles show a text card until you ask for the cover.
- **Quick menu (☰ / M)** opens any section without walking.
- **The Japanese resume follows 職務経歴書 section order** — 職務経歴 → 実績 →
  活かせる経験・知識・技術 → 学歴 → コンタクト — not a translation of the English CV.
  Section order is per-locale data.
- **Resume Mode** — plain scrolling HTML, reachable from the title screen, screen reader
  friendly, with a print stylesheet.
- **Touch support** down to 360 px wide; `prefers-reduced-motion` respected throughout.

## Tech

Vanilla JS (ES modules) + Canvas 2D. No framework, no bundler, no build step, no runtime
dependency except Google Fonts. `renderer.draw` runs at 1.2 ms median / 2.1 ms p95 per
frame (0.5 ms in the library scene): no `ctx.shadowBlur` in the draw loop, gradients and glows pre-rendered once, no
per-frame allocation, one `requestAnimationFrame` loop that stops when the tab is hidden.

Scenes, sprites, logos and showcase slides are generated by Python scripts in
[`tools/`](tools/) (numpy + pillow, fixed seeds), as is the media in this README —
[`tools/gh_media.py`](tools/gh_media.py) drives a headless browser over CDP to capture it
from the running game.

```
index.html · css/style.css
js/     main.js · i18n.js · audio.js
        engine/  camera · input · collision · particles · renderer
        world/   player · objects · map
        ui/      title · panels · resume
        data/    content.js
assets/ images · audio · PDFs
tools/  Python generators · dev server
```

## Run locally

```bash
python tools/serve.py     # → http://localhost:8123
```
